
The Twenty Pieces is a 2D treasure-hunting game built entirely in Java using Swing/AWT.  
This was my first ever programming project, created as a way to apply object-oriented programming concepts in a real application.

---
- Explore a 100x100 map  
- Collect treasures in stages:
  - 10 Bronze  
  - 5 Silver  
  - 3 Gold  
  - 1 Ultimate Treasure  
- Navigate using keyboard controls  'W,S,A,D'
- Avoid obstacles and find the final treasure  

---

## 🛠 Built With

This game was built using pure Java, without any external libraries or game engines.

It uses core OOP principles such as:

- Inheritance → Shared classes like `Entity` and `SuperObject`  
- Encapsulation→ Separation of concerns (player, UI, tiles, collision, game loop)  
- Polymorphism → Handling different treasure types through a common object structure  

Graphics, input handling, and rendering are implemented using:

- Java Swing
- Java AWT
